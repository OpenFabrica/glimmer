两个平台功能相同，按键按各自系统的习惯设计。表中 `⌥` 为 Option，`⌘` 为 Command，`⌃` 为 Control，`⇧` 为 Shift；
「—」表示该平台没有此键。

Linux 版（测试中）的按键与 Windows 列相同，IBus 与 Fcitx5 下一样，只有三点不同：没有悬浮状态条，中 / 英看系统顶栏的输入法指示器（IBus），或托盘图标与输入法面板（Fcitx5），也可以点它切换；
全角 / 半角标点只能在配置文件里改；暂不支持「翻译选中文字」。

## 切换模式

| 操作 | macOS | Windows |
|---|---|---|
| 中 / 英切换（英文为直通，按什么上什么） | 单击 `Shift` 或 `Caps Lock`（可在「偏好设置 → 快捷键」改用组合键） | 单击 `Shift`；或点击任务栏 / 悬浮状态条上的「中 / 英」 |
| 开关英文辅助（英文模式的补全、纠错、预测） | `⌃⇧E`（可在「偏好设置 → 快捷键」修改） | `Ctrl + Shift + E`（可在「设置 → 快捷键」修改） |
| 直接输入大写英文 | 英文模式下按住 `⇧` | `Caps Lock` 亮起（中英模式均可） |
| 输入拼音时临时输入一个大写字母 | `⇧ + 字母`：拼音原样上屏，再输入该大写字母 | 同左 |
| 切换全角 / 半角标点 | 中文全角、英文半角，不可更改 | 点击悬浮状态条上的「，。」格，中英各记一份 |
| 切换到其他输入法 | `⌃ + Space`（系统） | `Win + Space`（系统） |

英文辅助的快捷键中英模式下均可按，开着时模式指示显示「英+」，见 [英文辅助](../input/english-mode.md#英文辅助)。
它需为修饰键加字母；与中 / 英切换或「翻译选中的文字」的组合键相同时不起作用，按键交给应用。Windows 上修改后需切换到其他输入法再切回微明才生效。

Windows 的主键盘数字和常用标点按当前系统键盘布局识别；非美式布局的字母、AltGr 和组合音符输入仍有局限。

## 输入组句时（拼音 / 注音）

macOS 的单击 Shift 需在半秒内松开；Shift 与字母、其他修饰键或鼠标组合时不切换，长按也不切换。使用 Shift 或组合键切换时，未完成的输入原样上屏；组合键长按只切换一次。当前模式以菜单栏「中 / 英」为准，Caps Lock 指示灯不单独代表当前模式。

| 操作 | macOS | Windows |
|---|---|---|
| 上屏高亮候选（无候选时上屏所敲的拼音 / 注音） | `Space` | `Space` |
| 上屏当前页第 N 个 | `1` 至 `9` | `1` 至 `9` |
| 将拼音字母 / 注音符号原样上屏 | `Enter` | `Enter` |
| 删除光标前一个字母 / 注音 | `Backspace` | `Backspace` |
| 删除光标后一个字母 | `Delete` | — |
| 删除光标前一个音节 | `⌥ + Backspace` | — |
| 删除光标前全部拼音 | `⌘ + Backspace` | — |
| 清空 | `Esc` | `Esc` |
| 移动高亮（到页边自动翻页） | `↑` / `↓` | `↑` / `↓` |
| 翻页 | `[` `]`、`PageUp` / `PageDown`、`⇧ + Tab`（上一页） | `[` `]`、`PageUp` / `PageDown` |
| 接受云端整句补全 | `Tab`；无补全时翻页 | `Tab`；无补全时交给应用 |
| 移动拼音光标 | `←` / `→` | `←` / `→` |
| 按音节移动光标 | `⌥ + ←` / `⌥ + →` | — |
| 光标移到开头 / 末尾 | `⌘ + ←` / `⌘ + →`，或 `Home` / `End` | `Home` / `End` |

光标停在中间时，候选只按光标之前的拼音计算（`ni|hao` 出 你）；上屏后其余拼音保留，光标移到末尾。
若前面某个音节输入有误，macOS 上可按 `⌥ + ←` 移到其后、`⌥ + Backspace` 删除后重输、`⌘ + →` 回到末尾。

### 注音模式

「偏好设置 → 通用」（Windows：「设置 → 通用」）的「拼音方案」选「大千注音」后，组句中的按键改为：

| 操作 | macOS | Windows |
|---|---|---|
| 上屏高亮候选 | `Enter` | `Enter` |
| 将注音符号原样上屏 | `Shift + Enter` | `Shift + Enter` |
| 一声 / 轻声 | `Space` | `Space` |
| 声调与符号（进入组句，不选词） | 数字键，`-` `;` `,` `.` `/` | 同左 |

大千键盘布局把数字键与 `- ; , . /` 都分给了注音符号和声调，所以注音模式下这些键不再选词、不再翻页，选词用 `Enter`，也可先用 `↑` `↓` 移动高亮。
这一段还差声调时 `Space` 是一声 / 轻声，声调敲过之后 `Space` 照常上屏高亮候选。

翻页键对可改为 `,` `.` 或 `-` `=`：「偏好设置 → 快捷键」。

## 输入五笔时

开启 [五笔](../input/wubi.md) 并把拼音方案设成「关」（只打五笔）后，组句中的按键与上表相同，以下几处不同。86 五笔、98 五笔与新世纪五笔的按键完全一致：

| 操作 | macOS | Windows |
|---|---|---|
| 输入满四码且有完全相同编码的字词 | 首选自动上屏（可在「通用」页关闭） | 同左 |
| 输入的字母使得没有任何候选 | 前一段的首选自动上屏（顶字），该字母作为下一个字的第一码 | 同左 |
| 四码没有候选（空码）时按 `Space` / `Enter` | 编码字母原样上屏 | 同左 |
| 开着「整句输入」时连着打编码 | 不自动上屏、不顶字；超过四码后首选是整句，`Space` 上屏整句，选后面的字词只上屏开头那一段 | 同左 |
| 拼音反查 | `z` + 全拼，候选右侧标注五笔编码 | 同左 |
| `v` `u` | 均为编码键，不进入算式与码点输入 | 同左 |
| 删除光标前一个编码 | `Backspace` 或 `⌥ + Backspace`（五笔没有音节，两者相同） | `Backspace` |
| 按音节移动光标 | `⌥ + ←` / `⌥ + →` 每次移动一个编码 | — |

五笔与拼音方案同时开着就是[混输](../input/fuzzy-and-shuangpin.md#五笔与拼音混输)：上表只剩 `v` `u` 那一条不成立——混输下这两个键既是编码也是拼音，算式与码点改成 `Shift`+`V`、`Shift`+`U`，
其余按键与打拼音时完全一样（没有四码自动上屏、没有顶字上屏、没有 `z` 反查，删除与移动光标按音节走）。

## 英文模式下

下表为英文辅助开着时的按键；关着时英文模式为直通，按什么上什么。

| 操作 | macOS | Windows |
|---|---|---|
| 选择高亮候选 | `Space`、`Tab` | `Space`、`Tab` |
| 选择第 N 个候选（当前页没有第 N 个时，数字作为内容接在所敲字母后，如 `gpt6`） | 数字键 | 数字键 |
| 移动高亮 / 翻页 | `↑` / `↓`、翻页键 | `↑` / `↓`、翻页键 |
| 原样输出所敲字母 | `Enter`、标点 | 同左 |
| 接受预测的下一个词（词后敲 `Space`、显示预测时） | `Tab`：上屏该词与一个空格，接着显示再下一个词 | 同左 |

预测显示时只有 `Tab` 接受预测，其他键与没有预测时相同，按下后预测收起；数字键不选预测。预测显示出来之前按的 `Tab` 交给应用。没有预测、也没有在输入单词时，`Tab` 交给应用。见 [预测下一个词](../input/english-mode.md#预测下一个词)。

中文模式下输入拼音时敲半角标点，缺省进入英文直输段；「设置 → 通用 → 打拼音时敲标点」可改为先上屏候选再出标点，或按输入像不像英文自动判断，见 [快捷输入](../input/shortcuts.md#中英混输)。

没有候选时数字直接接在字母后（`xq1`）；带数字的标识符先按 `Enter` 输出字母再敲数字。

## 译词与删除候选

| 操作 | macOS | Windows |
|---|---|---|
| 上屏第 N 个候选的第一条译词 | `⌥ + 数字` | `Ctrl + 数字` |
| 上屏第二条译词（候选右侧有两条时） | `⇧⌥ + 数字` | `Ctrl + Shift + 数字` |
| 删除第 N 个候选 | `⇧ + 数字` | `Shift + 数字` |

仅在输入拼音时有效。三组修饰键在「偏好设置 → 快捷键」（Windows：「设置 → 快捷键」）录制修改；
macOS 上应避开 `⌃ + 数字`（系统切换桌面）与 `⌘ + 数字`（应用切换标签页），Windows 上 `Alt + 数字` 会被应用作为菜单快捷键截获。
删除候选的说明见 [译词与生词](../learning/translation.md#删除不需要的候选)。

## 云联想

| 操作 | macOS | Windows |
|---|---|---|
| 翻译应用中选中的文字 | `⌃⌥T` | `Ctrl + Alt + T` |
| 翻译结果：替换选区 | `Enter` / `Space` / `1` | 同左 |
| 翻译结果：保留原文 | `Esc` | `Esc` |
| 问字 | 输入 `u`（双拼下 `Shift`+`U`）再输入拼音；勾选「敲 ? 也进入问字」后未输入拼音时输入 `?` 再接拼音同样可用 | 同左 |

均需先打开云联想，见 [问字与翻译](../cloud/question-and-translate.md)。翻译快捷键可修改；Windows 上修改后需切换到其他输入法再切回微明才生效。

## 前缀键

| 输入 | 结果 |
|---|---|
| `rq` / `sj` / `xq` | 日期 / 时间 / 星期 |
| `v` + 算式或数字 | 算式结果、中文数字与金额（`v123.5` → 壹佰贰拾叁元伍角）；双拼下以 `Shift`+`V` 开头 |
| `u` + 十六进制 | 该码点对应的字符；双拼下以 `Shift`+`U` 开头 |
| `u` + 拼音 | 问字（需打开云联想）；`?` + 拼音需在「快捷键」页勾选后可用 |

两个平台相同，详见 [快捷输入](../input/shortcuts.md)。`v` 与 `u` 可在「快捷键」页改为 v、u、i 三者之一。只打五笔时这些字母都是编码，前缀键不可用（`?` 除外）；混输下与双拼一样，按住 `Shift` 用。
