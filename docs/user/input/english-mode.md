英文模式分两层：

- **英文模式本身是直通**：按什么上什么，与系统自带的英文输入一致。`Shift` 只在中文与这种英文之间切换。
- **英文辅助**是英文模式上的一个设置：开着时输入字母给出补全与拼写纠正，词后敲 `Space` 预测下一个词（`Tab` 接受）。缺省开启，可随时用快捷键开关，见 [英文辅助](#英文辅助)。

## 进入英文模式

- **macOS**：默认单击 `Shift` 或按 `Caps Lock` 在中文与英文之间切换，菜单栏「中 / 英」立即显示当前模式。
- **Windows**：单击 `Shift`（按下即松开，不与其他键组合）在中 / 英之间切换，任务栏右下同步显示「中」或「英」，Caps Lock 亮着时显示「A」。
  反向同样有效：点击任务栏的「中 / 英」图标，微明随之切换（悬浮状态条一并更新）。
  `Caps Lock` 在 Windows 上只控制大小写：亮起时无论中英模式均直接输出大写英文字母（与微软拼音一致）；`Shift` + 字母同样输出大写。

### 修改 macOS 切换快捷键

打开「偏好设置 → 快捷键」，点击「切换中文 / 英文」右侧按钮，单击 Shift，或按下修饰键加字母组合（例如 `⌃⌥M`）；`Esc` 取消。组合键不能与「翻译选中的文字」相同，数字键留给候选操作。若组合键被系统或应用占用，请换一组。

修改后即时生效；「恢复默认快捷键」会恢复单击 Shift。已设置的组合键在升级后保留，改用 Shift 需重新录制或恢复默认。

左右 Shift 均可使用，需在半秒内按下再松开；长按、Shift 与字母或其他修饰键组合、Shift 配合鼠标选择文字时均不切换。Shift + 字母仍输入大写。

Shift 或组合键切换会将未完成的拼音或英文原样上屏，收起候选或翻译窗口。切换结果在输入框之间保留，退出输入法进程后重置。切换后 Caps Lock 指示灯可能与实际模式不同，请看菜单栏「中 / 英」。

## 悬浮状态条（Windows）

任务栏的「中 / 英」不易察觉时，可另开一条**桌面上的悬浮状态条**：「设置 → 候选窗口」打开「悬浮状态条」。它有三格：

| 格 | 显示 | 点击 |
| --- | --- | --- |
| `中` / `注` / `英` / `英+` | 当前模式（开启大千注音时显示「注」，双拼时显示为「中 · 小鹤双拼」，五笔时显示所选版本，如「中 · 86 五笔」「中 · 新世纪五笔」；英文模式下英文辅助开着时显示「英+」） | 切换中 / 英，与单击 `Shift` 相同 |
| `，。` / `,.` | 当前模式下标点是否转为全角。中英各记一份，缺省中文全角、英文半角，切换模式时随之切换 | 切换当前模式的全角 / 半角 |
| ⚙ | | 打开设置 |

按住拖动可移到屏幕任意位置，位置会被记住；外观随系统的深浅色与缩放。
它只在当前输入法为微明时显示：切换到微软拼音等其他输入法时收起，切回后再次出现；关闭某个应用不影响它。它与任务栏图标并存。

## 英文辅助

英文辅助开着时，英文模式下输入字母给出补全与拼写纠正，词后可预测下一个词。关着时英文模式为直通，按什么上什么，与系统自带的英文输入一致。

### 开关

- **快捷键**：macOS `⌃⇧E`，Windows 与 Linux `Ctrl + Shift + E`。按下即开关，设置随之保存，立即生效。
  正在输入的英文字母原样上屏，不会丢失。中文模式下按同样有效，下次切到英文模式时生效。
- **菜单（macOS）**：输入法菜单中的「英文补全、纠错、预测」，勾选表示开启，右侧显示快捷键。
- **偏好设置**：「偏好设置 → 通用」（Windows：「设置 → 通用」）的「英文模式带补全、纠错、预测」。Linux 暂无设置界面，用快捷键开关。

当前状态看模式指示：英文辅助开着时显示「英+」，关着时显示「英」。macOS 看菜单栏，Windows 看悬浮状态条，Linux 看 IBus 输入法面板上的模式项。

快捷键可在「偏好设置 → 快捷键」（Windows：「设置 → 快捷键」）的「开关英文辅助」修改，需为修饰键加字母。
若与「切换中文 / 英文」或「翻译选中的文字」相同，或没有修饰键、不是字母，此快捷键不起作用，按键交给应用。
Windows 上修改快捷键后，需切换到其他输入法再切回微明才生效。

### 行为

英文辅助开着时，英文模式下输入字母，候选窗口给出英文词的补全与拼写纠正。字母缺省小写，按住 `Shift` 输出大写。

- **跟着前文变**：候选的先后参考前面刚输入的一两个英文词，同样的字母在不同的词后面给出的候选不同。句号、问号、叹号之后按句首处理（macOS 上换行也是）；
  切换应用、切换中英模式或停顿 5 秒以上之后不再参考前文（macOS 上移动光标、删除已上屏的字之后也是）。
- **拼错也能给出想打的词**：4 个字母起，敲错一个字母（按到旁边的键、两个字母顺序颠倒、多按或漏按一个字母）时仍给出想打的词，
  词没打完也可以：`tomm` 给出 tomorrow，`recie` 给出 receive，`seperate` 给出 separate。8 到 12 个字母的词错两处也能纠正。
- **带撇号的词**：`dont` 给出 don't，`im` 给出 I'm，`well` 先给 well、其后是 we'll。
- **所敲字母本身是一个词时排第一**：`or`、`may` 第一个候选就是小写的 or、may，按 `Space` 不会被换成别的写法或别的词。
  输入小写的 `id`、`api`、`google` 时，更常见的大写写法（ID、API、Google）排在第二个，按 `2` 即可选择。

选词与中文模式一致：`Space` 选高亮候选（词上屏后空格照常输入），数字键选当前页第 N 个（没有第 N 个时数字接进单词，如 `foo1`），翻页键翻页，`↑` / `↓` 移动高亮，`Tab` 同样选高亮项。
**`Enter` 与标点将所敲字母原样上屏**：项目名、人名这类词表中没有的词（如 `openfabrica`）按 `Enter` 即可原样输出；没有候选时 `Space` 也原样上屏。
带数字的标识符（`mp3`、`utf8`）先按 `Enter` 输出字母再敲数字；没有候选时数字直接接在字母后。

标点在 macOS 上一律半角；Windows 上缺省半角，需要全角时见上文悬浮状态条。

### 预测下一个词

英文词上屏后敲 `Space`，候选窗口显示最可能的下一个词。只显示一个词，它的序号位置显示 `⇥`。

- 按 `Tab` 接受：上屏这个词和一个空格，接着显示再下一个词。可以连续按 `Tab`。
  预测显示出来之前按的 `Tab` 交给应用，不接受预测。用鼠标点击预测不会上屏。
- 只有 `Tab` 接受预测。其他键与没有预测时相同，按下后预测收起：字母开始输入下一个词，数字、标点、`Space` 原样输入。
  数字键不选预测，`have 2 cats` 中的 `2` 不会被替换。
- 接受的词后面带一个空格。下一个字符是标点时，需先按 `Backspace` 删除这个空格。
- 接受过的词与选过的英文候选一样记入个人词表。
- macOS 上，词后先敲逗号再敲 `Space` 同样显示预测；用数字键或 `Enter` 上屏的词，之后敲 `Space` 也显示。
  Windows 与 Linux 上只在两种情况下显示：用 `Space` 选词上屏之后，按 `Tab` 接受预测之后。

以下情况不显示预测：

- 句首：句号、问号、叹号或换行之后的第一个词。
- 不知道前一个词：刚进入输入框，切换过应用或中英模式，移动过光标，删除过已上屏的字。
- 前一个词不在词表中，如按 `Enter` 原样上屏的项目名。
- 停顿 5 秒以上。已显示的预测在停顿 5 秒后收起。
- 无法确定下一个词时。
- 密码框中。Windows 与 Linux 上，浏览器无痕窗口里的输入框也不显示。
- 英文模式不给候选时：关闭了英文辅助，或在不给候选的终端与代码编辑器中。

不需要预测时，在「偏好设置 → 通用」取消「预测下一个词」（Windows：「设置 → 通用」的「预测下一个词（Tab 接受）」）。Linux 暂无设置界面，在配置文件 `[general]` 分节写 `english_prediction = false`。关闭英文辅助时预测一并停用。

### 按应用关闭

终端与代码编辑器中缺省不给候选，英文模式为直通，以免遮挡应用自身的补全或占用 `Tab` 键。
macOS 的名单包括 Terminal、iTerm、Warp、Ghostty、VS Code、Cursor、Zed、JetBrains 系列、Xcode 等；
Windows 的名单包括命令提示符、PowerShell、Windows Terminal、VS Code、Cursor、JetBrains 系列、Visual Studio 等。
「通用」页有一个勾选框控制此名单。需要增减具体应用时，在「高级」页打开配置文件，修改其中 apps 一段，每一项均附说明。
在此名单中的应用里，英文辅助开着时英文模式仍为直通。

## 记住用户的词

按 `Enter` 原样上屏过的英文词（如 `gist`、`python`）会记入个人词表，选过的英文候选同样记录。
下次完整输入这个词时它排在首位；只输入开头几个字母时，一个词只选过一次不会马上排到前面，多用几次才会靠前。
偶尔误选一次的词因此不会压过常用词。

中文模式下 `key`、`id` 这类末尾落单一个字母、既像英文词又可读成拼音的输入，若常选中文词（如「客一」「以的」），中文词排在前面，英文词退后；
勾选「中文候选排在英文词前面」后中文词一律在前。

## 与中文模式的关系

中文模式下整段输入为英文词时同样直接给出英文候选（`hello` 先英文再拼音，勾选「中文候选排在英文词前面」后英文排第二），拼音不成立时还会补全前缀（`compa` → company）；取消「输入拼音时也给英文词候选」后中文模式不再给英文词。
无需切换到英文模式，见 [快捷输入](shortcuts.md)。
