- **macOS**：从输入法菜单打开（菜单栏「中 / 英」状态项，或系统输入源菜单中微明的几项），名为「偏好设置」。
- **Windows**：开始菜单的「微明设置」，或悬浮状态条上的 ⚙，名为「设置」。

常规设置修改即时生效；自定义短语的启用开关即时生效，新增或编辑在点击「保存规则」后生效。

### 检查更新

「关于」页的「检查更新」按钮会从 GitHub 下载一份版本清单，与当前版本比较；有新版本时显示版本号、日期与第一条更新日志，并出现「下载并安装」按钮。
点它会把安装包下到数据目录的「updates」文件夹，校验通过后自动打开安装器（macOS 是系统的安装器，Windows 是安装向导），之后按安装器的提示做即可；安装完成后 macOS 需注销再登录或重新选择输入法，Windows 上已打开的程序需重启。
下载失败或校验不符时会提示重试，不会安装来路不明的文件。

「自动检查更新」缺省打开：macOS 在输入法启动半分钟后查一次，之后每 12 小时查一次；Windows 在打开设置程序时查，同样 12 小时内不重复。每次只下载几 KB 的清单，不带任何个人信息；
有新版本时 macOS 在输入法菜单的版本行后面标「新版本 x 可用」，菜单里也有「检查更新…」直达「关于」页；两个平台都不会自动安装。关掉后只有手动点按钮才查。
对应配置文件的 `[update]` 分节（`check` 开关与清单地址 `feed_url`）。

Linux 的 deb 包没有应用内更新，直接安装新版 deb 即可。

### 繁体输出

打开「繁体输出」后，候选与上屏文字按 OpenCC 转成繁体（只换字形，不换用语：软件 → 軟件）。云端词与整句补全同样转换。引擎内部仍按简体处理：用户词、词频、输入统计与输入日志都记简体，译词照常显示。

## 配色

「候选窗口」页的「配色」有五套：默认（白底浅绿高亮）、海蓝（蓝底白字高亮，像系统菜单）、暖纸（米黄底）、樱粉（淡粉底）、素灰（深灰高亮配白字）。
每套都有浅色、深色两版，跟着「外观」切换。

想用自己的颜色时，可以单独改「背景颜色」（候选窗口的底色）和「高亮颜色」（当前候选的底色）：
macOS 点色块挑颜色，点「恢复配色的颜色」回到配色自带的颜色；Windows 在框里填 `#RRGGBB` 形式的颜色，清空就回到配色自带的颜色。
自己挑的颜色不分浅色深色。文字颜色按底色深浅自动选：深底配浅字，浅底配深字。

配色只对微明渲染器生效；选「系统绘制」时用系统的颜色。Linux 的候选窗口由 Fcitx5 / IBus 绘制，颜色跟随它们的主题。
对应配置文件 `[general]` 分节的 `color_scheme`、`background_color`、`highlight_color`。

## 横排与拼音位置

横排时候选排成一行，仅高亮候选在下方单独一行显示译词，页码在行尾。
「只在窗口」显示拼音适用于终端与部分 Electron 应用，这类应用对行内拼音的渲染效果较差。

## 输入法菜单（macOS）

云联想开关、模糊音子菜单、偏好设置、打开日志目录、版本号。配置文件解析失败时增加一条灰色的错误说明，此时沿用上一份可用的配置，输入法不退出。

## 直接修改配置文件

全部设置保存在一个配置文件中，「高级」页有「在编辑器中打开配置文件」，文件内每一项均附说明。保存后一秒内生效，无需重新切换输入法。

五笔相关的项：`[general]` 分节的 `wubi` 留空为拼音，填 `86`、`98` 或 `xsj` 分别开启 86 五笔、98 五笔与新世纪五笔（新世纪也接受 `06` 与 `xinshiji`）；`[wubi]` 分节是五笔的行为：
`auto_select`（四码自动上屏，缺省开）、`hint`（编码提示，缺省开）、`fixed_order_length`（不超过这么多码的候选只按码表顺序、不随使用习惯调整，缺省 2）、`sentence`（整句输入，缺省关；开着时四码自动上屏与顶字上屏不再生效）。随包码表只含常用字。

## 自定义短语（macOS）

「自定义短语」页以常驻表格显示启用状态、内容和固定候选位置，可直接勾选启用或停用。点击「+」新增，双击已有行或点击「编辑…」修改，选中后点击「−」删除。新增或编辑时，填写 1–32 个小写英文字母的输入码、1–9 的候选位置和文本，点击「保存规则」。文本可以包含空格、换行、地址、长回复或标点，按原样输出；候选窗口只展示长文本的简短预览。

例如将 `ee` 的第 1 位设置为 `：`，第 2 位设置为 `；`，输入 `ee` 后按空格选择首项，按 2 选择第二项。普通拼音候选填入其他位置，学习与模型重排不会改变自定义位置；云端词只使用不影响固定位置的剩余格。若固定位置超过第一页容量（例如第 9 位、每页 5 项），本次查询不显示云端词。位置跨页时按当前页的序号选择。

同一个输入码的位置不能重复，新增和编辑冲突时提示并拒绝保存；停用规则也保留其位置。没有足够普通候选时保留空位，空位不能上屏。选择已有规则后可编辑、停用或删除。

编辑期间若规则被其他窗口或外部文件修改，保存会提示并保留草稿，不覆盖新规则。保存会保留现有短语条目的注释。

默认中文标点模式会保存，重启后仍生效；选择半角不会改变自定义短语中的全角标点。英文模式不触发自定义短语。

### 系统的文本替换

「自定义短语」页勾选「也使用系统设置『键盘 → 文本替换』里的条目」（缺省勾选）后，系统文本替换中的条目在输入拼音时同样可用：
输入码敲全后短语出现在该输入码最靠前的空位（页里的规则优先占位），`Space` 或数字键上屏。
只有输入码全为小写英文字母的条目可用；系统设置中新增或修改的条目在下次切换到微明时生效。它们不在页里的表格中列出，要改请到系统设置。
